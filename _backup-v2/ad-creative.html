Challenge

Three teams touch every ad creative. User acquisition proposes the idea, the creative team produces it, QC checks it, and it comes back to UA to run. This was tracked in Smartsheet and Excel, with briefs scattered across chats and sheets.

That made it hard to answer basic questions: what exactly was the brief, which step is this creative in, which visual styles still have no file, and why did a creative fail review?

My role

I'm the Product Owner. I owned the workflow and requirements: what each team needs at each step, what counts as "ready" to move on, and how a creative is judged and named.

  • Gathered requirements from user acquisition, creative and quality review, and turned them into one workflow from idea submission to campaign handoff.
  • Defined what a complete idea brief contains and what each production status means.
  • Designed the AI review criteria and prompts used for automated pre-review and naming.
  • Built dashboards for review outcomes, pipeline status, ad spend and performance, and used them to refine the workflow after launch.

The workflow

Every creative moves through six stages. The first four run on real data today. The last two, Running Campaign and Campaign End, are still being built and currently use mock data.

AI plus human QC

When a creative is handed over, the system opens a QC batch and treats every file as its own creative to be scored. QC has two layers:

  • AI pre-review scores the creative against a rubric and flags problems such as brand, policy, technical, copy or video issues.
  • Human review gives the final 1–5 rating and can edit the rubric notes. A creative only moves on if it clears the pass threshold, is not rejected, and has a usable file.

After QC, the system generates a standard name so everyone refers to the same creative the same way:

Key decisions

  • A structured idea card instead of a free-form brief. Persona, pain point, angle, hook, CTA, visual style and format are required fields, so creative gets the context to produce without asking again.
  • Keep reference files separate from deliverables. Files are attached per visual style, so it is obvious which style still has no finished file.
  • AI advises, humans decide. AI gives a score and a verdict, but a person makes the final call, which keeps accountability clear.
  • Group creatives into hypotheses before launch. A creative is tied to the thing UA wants to test, so results can later be read as learnings, such as which hook pulled users in, which art style converted, and which concept kept flopping.
